まず吐き出して、送れる形に整える。

その場で言葉が出てこない。後になって「ああ、こう返せばよかった」と思う。RoastMateは2段階で解決します：まず「吐き出し」（Proなら「罵倒」も）で自分だけのための草稿を書いて感情を逃がす。次にワンタップで送れる形に書き直す —— 鋭く、立場を保ちつつ、踏み外さない（入力に合わせた書き直しは、Apple Intelligenceを利用できる端末で動作します）。

状況を入力し、強度を選び（穏やか / 鋭い / 容赦なし / 罵倒 / 吐き出し）、スタイルを選んでください（高EQ、パッシブ・アグレッシブ、敬語、文学風、シェイクスピア風、MBAバズワード、容赦なし、ディベート終止符、ビジネス冷たい暴力など全24種類）。どこで生成されるかは、強度と端末によって異なります。

「吐き出し」と「罵倒」のプライベート下書きは、あなたが明示的に許可した場合のみ、開発者が運営するクラウドプロキシ経由で第三者LLMプロバイダに転送されて生成されます —— Appleのオンデバイスモデルは抑制的すぎて、本当の吐き出しには不向きだからです。クラウドで動くので、Apple Intelligenceの有無にかかわらず、入力内容に合わせた下書きが返ってきます。「設定 → AIとプライバシー」でいつでもオフにできます。オフにすると、吐き出し / 罵倒は入力内容からの生成ではなく、あらかじめ用意した例文の表示になります。

穏やか / 鋭い / 容赦なしでの生成、送れる形への書き直し、口論シミュレーターは、クラウドを使わず端末内で動作します。Apple Intelligenceを利用できる端末では、AppleのFoundation Modelsが入力内容から生成します。利用できない端末（iOS 18、macOS 14〜15、非対応機種、Apple Intelligenceがオフの場合など）では、あらかじめ用意した例文の表示になります（入力内容からの生成ではなく、クレジットも消費しません）。分析データのアップロードなし、広告識別子なし。

無料版では、生成1回につき1クレジットを使います（入力内容から生成された場合のみ。例文の表示と「送れる形にする」は対象外）。はじめての方には10クレジットと、最初の7日間は1日2回の無料生成があります。クレジットはアプリ内で追加購入もできます。

RoastMateは創作と感情表現のためのツールであり、特定の個人を標的にしたり嫌がらせをするためのものではありません。AIには実名を「上司」「ルームメイト」のような役割に置き換え、差別的表現や脅しを使わないよう指示しています。さらに、組み込みのセーフティフィルターが脅しや自傷に関わる一部の表現をブロックし、深刻な自傷のサインがある入力では生成せずに相談窓口を案内します。

機能

• 非公開の草稿モード：吐き出しは気持ちを軽くするため、罵倒（Pro）はより強く発散するため。どちらもワンタップで送れる形に書き換え
• 5段階の強度：穏やか / 鋭い / 容赦なし / 罵倒 / 吐き出し（容赦なし・罵倒はPro）
• 24種類のスタイル（うち8種類は無料）
• 返信ヘルパー：受け取ったメッセージを貼り付けて返信案を生成
• 口論シミュレーター（Pro）：難しい会話を事前にリハーサル、AIが相手役
• 気持ち翻訳：本音をちょうどいい言葉に書き換え
• SNS返し：投稿やツイートを貼り付けて返信案を生成
• 出来事スレッド：相手がまた返してきた？同じ事柄の続きを生成
• サンプル集：17の作例で、入力なしでも操作感を確認（作例の返しは主に英語と中国語）
• macOSメニューバーから即起動
• Siri & ショートカット対応
• iOS共有メニュー拡張
• 対応言語：英語、中国語（簡体字・繁体字）、日本語

※吐き出し / 罵倒以外の生成は、Apple Intelligenceを利用できない端末では用意された例文の表示になります。

Pro

• 罵倒：Pro限定のプライベート下書き（クラウド、要許可）
• 容赦なし：送れる範囲でいちばん鋭い強度
• 全24スタイル解放
• 送れる返しは毎回3パターン（無料版は1パターン）
• 複数ターンの口論シミュレーター
• 履歴無制限
• クレジット不要

※Apple Intelligenceを利用できない端末では、容赦なしと口論シミュレーターは用意された例文の表示になります。罵倒はクラウドで動くため、どの端末でも入力内容から生成されます（要許可）。

プライバシー

「穏やか / 鋭い / 容赦なし / 送れる形にする」はクラウドを使わず端末内で処理されます（ネットワーク不要）。Apple Intelligenceを利用できる端末ではAppleのオンデバイスFoundation Modelsが生成し、利用できない端末では用意された例文を表示します。「吐き出し / 罵倒」は明示的な許可があった場合のみ、当方が運営するCloudflare上のプロキシ経由で第三者LLMプロバイダに転送されます（当方プロキシは内容を保持しません。1日の利用上限があり、その管理にはインストールごとのランダムなIDを使います。Proの方は、購入確認のためAppleの署名付き購入情報も当方プロキシに送られます。「設定 → AIとプライバシー」でいつでもオフにできます）。Appleサインインは任意で、サインインした場合のみ、Appleが発行する安定したユーザーID（Appleから氏名・メールアドレスが提供された場合はそれも）をこの端末内にだけ保存します。分析SDKなし、広告識別子なし、デバイスフィンガープリントなし。
