Reviewer notes for RoastMate v1.3.1:

1. WHERE GENERATION RUNS (on-device first, consented cloud for two modes).
   Calm / Sharp / Savage and the "Make it sendable" rewrite run ON-DEVICE
   using Apple's Foundation Models framework (LanguageModelSession) on
   devices that have it. The rewrite is on-device only, always.

   Vent and Feral are different, and we want to be explicit about it:
   Apple's on-device model refuses to produce genuine vent output (its
   guardrails reject the register), so these two modes send the user's
   typed situation to OUR developer-owned Cloudflare Worker proxy, which
   forwards it to a third-party LLM provider (currently Groq; OpenRouter
   as fallback). This happens ONLY after the user grants an explicit,
   separate in-app consent (Guideline 5.1.2(i)), shown before any text
   leaves the device and revocable anytime in Settings → AI & Privacy.
   The proxy is stateless — we do not retain the text.

   The 虚拟舍友群 ("roommate group") feature in the Echoes tab is
   cloud-only for the same reason, behind the same consent.

   NOTE: an earlier version of this document said the app was on-device
   only and suggested verifying in Airplane Mode. That has not been
   accurate since the cloud Vent lane shipped, and it is corrected here.

2. POSITIONING — VENT FIRST, SEND LATER.
   RoastMate is a creative-writing + emotional-expression tool, not a
   harassment tool. There is no field to enter a target person's name;
   the Generator accepts only a description of a *situation*, never an
   individual's identity. Safe Mode is on by default (Settings → AI &
   Privacy).

   The app exposes 5 intensity levels (Calm / Sharp / Savage / Feral /
   Vent). "Feral" and "Vent" both produce PRIVATE drafts that are
   clearly labelled "for yourself only" in the UI and are NOT
   presented as messages to send. Feral allows stronger profanity for
   catharsis; Vent is the milder private-draft option. A separate
   user-initiated "Rewrite as Sendable" action runs a second on-device
   generation that strips profanity, adds tone control, and produces an
   outward-facing reply that respects all the safety rules (no slurs,
   threats, sexual content, doxxing, or identity attacks).

   REVIEWER TEST PATH for Vent Mode:
   a. Open the Roast Generator. In the Intensity row pick "Vent".
   b. Type any situation, e.g. "My boss took credit for my work".
   c. Tap Generate. The output card is labelled "Vent draft · for
      yourself only" with a disclosure banner that says not to send it.
   d. Tap "Make it sendable". A second card appears below labelled
      "Sendable reply" — this is the version the user is meant to
      actually send. It will not contain profanity or threats.
   The sendable rewrite runs on-device from a fresh LanguageModelSession
   with stricter instructions.

3. WHAT'S NEW IN 1.3.1 — PRIVATE DRAFTS ARE NOW UNSHAREABLE.
   This release removes every in-app affordance for sharing a private
   vent draft, so the "for yourself only" label is enforced and not just
   stated:
   - The share-as-image card previously offered an opt-in to include the
     raw vent draft, editable before rendering. That is removed. The card
     now renders ONLY the sendable reply, and its text is immutable —
     there is no free-text field anywhere in the compose path, so nothing
     a user types can be rendered onto a RoastMate-branded image. The
     rendered text is always model output that already passed the app's
     on-device safety filter.
   - The system share sheet and text selection are no longer offered on
     private drafts (they remain on sendable output).
   Copy is deliberately kept on private drafts as an explicit,
   user-initiated action.

4. SAMPLE DATA FOR REVIEW.
   On first launch the History tab is pre-seeded with 15 curated
   sample situations clearly labeled "Sample". The reviewer can tap
   any of them to see the full generation flow without typing.
   Samples can be cleared via Settings → Clear sample data.

5. ACCOUNTS / SYNC / SHARING.
   Sign in with Apple is OPTIONAL — used only to display the user's name
   on the Settings → Account screen. The app is fully functional without
   signing in; no feature is gated by sign-in. When the user signs in,
   only the Apple-issued stable User ID (and the name they choose to
   share, including email if provided) is stored locally in the device
   Keychain via App Group
   ($(TeamIdentifierPrefix)group.yyh.roastmate.app). We never see a real
   Apple ID; Private Relay emails are respected.

   iCloud sync IS ACTIVE (it was described as "planned" in earlier
   versions of this document; that is corrected here). History, threads,
   saved situations, settings and credit-ledger entries are mirrored via
   SwiftData + CloudKit into the PRIVATE database of the Apple Account
   signed in on the device (container iCloud.yyh.roastmate.app), which is
   what makes history available across the user's devices. This is the
   user's own iCloud storage: it never reaches our servers and we cannot
   read it. It follows the device's iCloud state.

   No user-generated content is shared between users. No social features.
   No analytics SDK, no advertising IDs, no third-party SDKs of any kind.

6. SUBSCRIPTIONS AND IN-APP PURCHASES.
   - Monthly:  yyh.roastmate.app.pro.monthly  ($2.99 / month)
   - Yearly:   yyh.roastmate.app.pro.yearly   ($19.99 / year, 7-day trial)
   - Consumable credit packs: yyh.roastmate.app.credits.10 / .70 / .160 /
     .380 (pay-as-you-go alternative to a subscription).
   Sandbox tester credentials: not required. Any sandbox tester account
   can be used to test the purchase flow; no pre-provisioned tester
   has been set up for this review.

   Pro entitlement is verified server-side: the app sends the StoreKit 2
   transaction JWS to our Worker, which validates Apple's signature and
   issues a short-lived session token used only to grant the higher cloud
   quota. The JWS carries no name, email, or payment detail.

7. APP GROUP.
   group.yyh.roastmate.app is a local shared container for the app family
   (for example the iOS app and iOS Share Extension), used for Keychain
   access. Cross-device sync is CloudKit, described in #5.

8. CAPABILITIES.
   - iOS Share Extension (yyh.roastmate.app.share): receives text from
     other apps via the system Share menu, generates one response, lets
     the user copy. Restricted to the Calm / Sharp intensities — it
     cannot produce a private vent draft.
   - watchOS app: quick roast from templates or dictation, with
     NSUserActivity Handoff to the iPhone.
   - macOS app: full feature set plus MenuBarExtra for one-click quick
     roast.
   - App Intents: GenerateRoastIntent registered for Siri, Spotlight,
     and Shortcuts. Exposes only Calm / Sharp.

9. AGE GATE.
   17+ rating selected proactively for mature humor / sarcasm. First
   launch shows an age confirmation screen the user must dismiss.
