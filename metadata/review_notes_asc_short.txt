Reviewer notes — RoastMate v1.5.0

1. WHERE GENERATION RUNS, AND WHAT A DEVICE WITHOUT APPLE INTELLIGENCE GETS.
Calm / Sharp / Savage and the "Make it sendable" rewrite run ON-DEVICE via
Apple's Foundation Models. The app also supports iOS 18 / macOS 14, where
Foundation Models does not exist. On such a device — or with Apple
Intelligence off, or while its assets are still downloading — those modes
return a small set of CURATED EXAMPLE responses instead of a model answer.
Every surface that can show such a response labels it ("Curated example — not
generated from what you typed. No credit used."): the Roast Generator, the
Explore tools, the Argument Simulator, History, the Share Extension and the
Siri result. NO credit is charged for it. This is intended behaviour, not a
failure. With Apple Intelligence enabled you get real, input-specific output.

Vent and Feral are different and we want to be explicit: Apple's on-device
model refuses to produce genuine vent output, so these two modes send the
typed situation to our own Cloudflare Worker, which forwards it to a
third-party LLM provider (currently Groq, OpenRouter as fallback). This
happens ONLY after a separate, explicit in-app consent (Guideline
5.1.2(i)) shown before any text leaves the device, revocable anytime in
Settings > AI & Privacy. Our proxy is stateless; we do not retain text.
Because they use that path, Vent and Feral produce real input-specific
output on ANY device, including one with no Apple Intelligence. The
"roommate group" in the Echoes tab is cloud-only for the same reason,
behind the same consent.

2. POSITIONING.
A creative-writing / emotional-expression tool, not a harassment tool.
No field for a target person's name — only a SITUATION. Safe Mode on by
default. Vent and Feral produce PRIVATE drafts labelled "for yourself
only", not presented as messages to send. A user-initiated "Rewrite as
Sendable" runs a second pass that strips profanity, slurs, threats,
sexual content and doxxing.

TEST PATH: Roast Generator > Intensity "Vent" > type any situation >
Generate. The card is labelled "Vent draft - for yourself only" with a
do-not-send banner. Tap "Make it sendable" for the sendable version.

3. WHAT'S NEW IN 1.5.0.
- Curated example output is now labelled on every surface and is never
  charged. Previously it was unlabelled and did cost a credit. The wallet
  gate no longer blocks a generation that can only return an example.
- Traditional Chinese: the curated examples now have a Traditional-script
  set. zh-Hant users previously saw Simplified characters.
- Safety filter: added the missing Traditional-script forms of several
  self-harm and violence phrases, so zh-Hant input and output are screened
  identically to zh-Hans, in both directions.
- Some capabilities ship DISABLED behind remote flags.

4. iCLOUD SYNC IS ACTIVE. History, threads, saved situations, settings and
credit-ledger entries mirror via SwiftData + CloudKit into the PRIVATE
database of the Apple Account on the device (container
iCloud.yyh.roastmate.app) — the user's own storage. It never reaches our
servers and we cannot read it.

5. ACCOUNTS. Sign in with Apple is OPTIONAL and gates no feature; only the
Apple user ID and any shared name are stored locally in Keychain. No
content shared between users, no social features, no analytics or
advertising SDKs, no third-party SDKs.

6. PURCHASES (unchanged from 1.3.1).
- yyh.roastmate.app.pro.monthly ($2.99/mo)
- yyh.roastmate.app.pro.yearly ($19.99/yr, 7-day trial)
- Consumable credit packs: .credits.10 / .70 / .160 / .380
Pro is verified server-side: the app sends the StoreKit 2 transaction JWS
to our Worker, which validates Apple's signature and issues a short-lived
token for the higher cloud quota. The JWS carries no name, email or
payment detail.

7. Share Extension and App Intents expose only Calm / Sharp — neither can
produce a private vent draft. 17+; first launch shows an age gate.
