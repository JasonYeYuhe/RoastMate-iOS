Reviewer notes — RoastMate v1.3.1

1. WHERE GENERATION RUNS.
Calm / Sharp / Savage and the "Make it sendable" rewrite run ON-DEVICE via
Apple's Foundation Models (LanguageModelSession) where available; the
rewrite is on-device only.

Vent and Feral are different and we want to be explicit: Apple's on-device
model refuses to produce genuine vent output, so these two modes send the
typed situation to our own Cloudflare Worker, which forwards it to a
third-party LLM provider (currently Groq, OpenRouter as fallback). This
happens ONLY after a separate, explicit in-app consent (Guideline
5.1.2(i)) shown before any text leaves the device, revocable anytime in
Settings > AI & Privacy. Our proxy is stateless; we do not retain text.
The "roommate group" feature in the Echoes tab is cloud-only for the same
reason, behind the same consent.

NOTE: earlier versions of this document said the app was on-device only
and suggested verifying in Airplane Mode. That stopped being accurate when
the cloud Vent lane shipped, and is corrected here.

2. POSITIONING.
A creative-writing / emotional-expression tool, not a harassment tool.
There is no field for a target person's name — only a description of a
SITUATION. Safe Mode is on by default.

Vent and Feral produce PRIVATE drafts, labelled "for yourself only" and
not presented as messages to send. A user-initiated "Rewrite as Sendable"
runs a second on-device pass that strips profanity and produces an
outward-facing reply (no slurs, threats, sexual content, or doxxing).

TEST PATH: Roast Generator > Intensity "Vent" > type e.g. "My boss took
credit for my work" > Generate. The card is labelled "Vent draft - for
yourself only" with a do-not-send banner. Tap "Make it sendable" for the
sendable version.

3. WHAT'S NEW IN 1.3.1 - PRIVATE DRAFTS ARE NOW UNSHAREABLE.
This release removes every in-app way to share a private vent draft, so
the "for yourself only" label is enforced rather than merely stated:
- The share-as-image card previously offered an opt-in to include the raw
  vent draft, editable before rendering. Removed. The card now renders
  ONLY the sendable reply, and its text is immutable — there is no
  free-text field in the compose path, so nothing a user types can be
  rendered onto a RoastMate-branded image. Rendered text is always model
  output that passed the app's on-device safety filter.
- The system share sheet and text selection are no longer offered on
  private drafts (both remain on sendable output).
Copy is deliberately kept as an explicit user-initiated action.

4. iCLOUD SYNC IS ACTIVE (described as "planned" in earlier versions of
this document; corrected here). History, threads, saved situations,
settings and credit-ledger entries mirror via SwiftData + CloudKit into
the PRIVATE database of the Apple Account on the device (container
iCloud.yyh.roastmate.app). This is the user's own iCloud storage: it never
reaches our servers and we cannot read it. It follows the device's iCloud
state.

5. ACCOUNTS. Sign in with Apple is OPTIONAL and gates no feature; only the
Apple-issued user ID and any shared name are stored locally in Keychain.
No content is shared between users. No social features. No analytics SDK,
no advertising IDs, no third-party SDKs.

6. PURCHASES.

- yyh.roastmate.app.pro.yearly ($19.99/yr, 7-day trial)
- Consumable credit packs: .credits.10 / .70 / .160 / .380
Pro entitlement is verified server-side: the app sends the StoreKit 2
transaction JWS to our Worker, which validates Apple's signature and
issues a short-lived token granting the higher cloud quota. The JWS
carries no name, email, or payment detail. Any sandbox tester works.

7. EXTENSIONS. Share Extension and App Intents expose only Calm / Sharp —
neither can produce a private vent draft. watchOS quick roast + Handoff.
macOS adds a MenuBarExtra.

8. AGE GATE. 17+ for mature humor; first launch shows an age confirmation.
