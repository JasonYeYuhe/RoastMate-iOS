# RoastMate macOS v1.0.6 (build 14) — What's New (first Mac release)

macOS's first live release (the prior macOS v1.0.1 was rejected under
Guideline 4 and never shipped; this build fixes that and rides the current
1.0.6 codebase, so it shares the iOS version number). Whats-New blurb framed
as "now on Mac" since no Mac users have had it before.

## en-US

· RoastMate comes to Mac — turn what's got you mad into a witty, sendable comeback right from your desktop or menu bar. Most modes run on Apple's on-device AI, so your text stays on your device.
