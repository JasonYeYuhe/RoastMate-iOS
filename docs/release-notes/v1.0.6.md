# RoastMate v1.0.6 (build 13) — release notes draft

Generated 2026-05-28 for ASC submission. Ships AFTER v1.0.5 clears
review.

## User-visible change

New **Echoes / 替你出气** feature — write down what's got you mad and
two synthetic "Echoes" back you up in a short chat-style transcript,
then bridge you to the rewrite tool with one tap. Pro feature. zh-Hans
only in this release; other languages will follow.

## Apple review notes

- New feature: Echoes generates a 4-6 message chat-style transcript
  of synthetic personas backing the user about a grievance. Persistent
  banner says "Echoes are synthetic. RoastMate doesn't have other
  users" to defuse any 4.0 fake-user-content concern. Two personas,
  both clearly synthetic (no avatars, abstract handles like 回声·甲).
  Casual tone runs on-device; Feral tone optionally routes to the
  cloud with a **dedicated 5.1.2(i) consent surface** separate from
  the existing Vent cloud consent (Settings → Echoes Feral on the
  cloud — independently togglable). No new PII collection, no new
  background modes.
- New SettingsView entry exposes the Echoes Feral cloud consent
  toggle (settings.echoes_feral_cloud). Toggleable any time.
- v1 is gated to zh-Hans locale at the tile level; other-locale
  users do not see the entry.
- IAP catalog unchanged.
