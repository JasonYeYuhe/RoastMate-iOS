# RoastMate v1.0.6 (build 14) — release notes (Echoes ENABLED)

Build 14 carries Echoes (替你出气) + the remote kill-switch + telemetry/
re-entrancy fixes + the pre-ship audit fixes (Echoes output SafetyFilter,
generator double-spend guard, onboarding privacy copy). Supersedes the stale
build 13. Echoes ships ENABLED; the 35% parse-fallback kill-criterion measures
it in production and the kill-switch can disable it without a review cycle.

Per-locale What's New differs on purpose: Echoes is **zh-Hans-only** in v1
(the tile is locale-gated), so en / zh-Hant / ja users don't see it and their
notes are invisible polish only (the Share-completion fix shipped in v1.0.5).

## Apple review notes

- Where to find the new feature: "Echoes / 替你出气" is a Pro feature shown
  ONLY when the device language is Simplified Chinese (zh-Hans). To review it:
  set the device language to 简体中文, open the Explore tab, and tap the
  替你出气 tile (between Argument Simulator and Social Roast).
- What it is: the user types a personal grievance; 1–2 clearly-labelled
  synthetic AI voices ("回声·甲/乙", abstract handles, no avatars) reply in a
  chat-style transcript that validates → escalates → de-escalates → ends with a
  tappable line that pre-fills our rewrite tool. A persistent on-screen banner
  discloses the voices are synthetic AI and that RoastMate has no other users
  (Guideline 4.0). The transcript always includes a de-escalation beat.
- Privacy / 5.1.2(i): Echoes runs entirely on Apple's on-device Foundation
  Models in this version — no user text leaves the device. The "Feral" tone
  shows a dedicated consent sheet for FUTURE cloud use, but cloud routing is
  disabled in this build; nothing is sent to any third party. The consent
  toggle lives in Settings, independently revocable.
- Safety (1.x): both input and generated output pass our safety filter
  (self-harm / explicit-violence hard-rail → safe curated fallback). Framed for
  self-expression, not harassment.
- No new permissions or entitlements. IAP catalog unchanged.
- macOS v1.0.6 NOT in this submission (macOS train still on v1.0.1 in queue).
