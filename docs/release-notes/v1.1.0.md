First feature release. Ships the **虚拟舍友群 (Roommate Group)** — Echoes vNext.
zh-Hans-only, Pro-gated, cloud-generated (Apple's on-device FM structurally
blocks the harsh group-roast, so it routes through the consented cloud path,
same as Echoes Feral). Enabled via `roommate_group_enabled` (baked default
true; remote kill-switch is the prod safety net).

## App Review Notes (English — for the reviewer)

This version adds **"虚拟舍友群" (Roommate Group)**. To see it:
1. Set the device language to **Simplified Chinese (简体中文 / zh-Hans)** — the
   feature is zh-Hans-only in this version and the entry is hidden otherwise.
2. Be **Pro** (it's a Pro feature). In a review/sandbox context the paywall is
   the standard StoreKit one; a DEBUG build forces Pro.
3. Open the **Explore / 探索** tab → tap **「虚拟舍友群」**.
4. Type a everyday grievance, pick a tone, tap "发到舍友群".

What it does: generates a one-time, read-only group chat where **3 synthetic
characters** ("护短室友 / 毒舌室友 / 清醒室友") back the user up about the
grievance, ending in a CTA into the rewrite tool. Compliance:
- **4.0 / synthetic personas:** the characters are clearly labelled
  "**合成角色 · 非真人**" (synthetic characters · not real people) on a
  persistent banner. They are AI-generated — NOT real people, NOT contacts, NO
  real-person impersonation, no avatars/timestamps/online status.
- **5.1.2(i) / cloud consent:** generation runs in the cloud, and the app
  requests **explicit, dedicated consent before any cloud call** (the same
  consent surface as the existing Echoes Feral path). No content is sent
  without consent.
- Output passes the same safety filter as the rest of the app (no slurs,
  threats, self-harm, or attacks on protected attributes). It can be remotely
  disabled via the app's existing kill-switch if needed.

Everything else is unchanged from v1.0.6 (no new permissions/entitlements).
