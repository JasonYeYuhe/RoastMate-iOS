## 2. The real example

### How it was made

**The "before": the production Worker.**
- Endpoint: `POST https://roastmate-vent.yyyyy-yeyuhe.workers.dev/v1/vent`
- Body exactly as the task specified: `{situation, intensity:"vent", locale:"zh_TW", deviceId:"p21-<n>-1023"}`.
- Five HTTP requests in total: one was blocked at the edge, four reached the Worker.
- Script: `scratchpad/p21/call.py`. Every request and response is in `scratchpad/p21/calls.jsonl`.

**One difference from an in-app request.** The app also sends `styleName:"高 EQ"` and `styleId:"high_eq"`, its default free style. With a free style the Worker adds no style voice, but one system-prompt line changes:
- without a style: `Style hint: none. Write in the user's raw voice…`
- with 高 EQ: `Style hint: 高 EQ — but IGNORE this style's politeness…`

So these drafts are the free-tier kind of output, and also exactly what the web demo sends. They are not byte-identical to an in-app request.

**The "after": "Make it sendable" (「改成能發的」), on-device.**
- Where: this Mac, macOS 27.0.1, M1 Pro, Apple Intelligence on. **Not an iPhone.**
- Harness: `scratchpad/p21/harness/` (`build.sh`, `main.swift`), built on the 10-22 `fmperm` harness.
- **Production files compiled as-is:** `PromptBuilder.swift`, `StylePreset.swift`, `Intensity.swift`, `ModelRefusal.swift`, `SafetyFilter.swift` (+ `ForbiddenTerms.json` via the production `ResourceBundle.swift`), `RewriteThreatScreen.swift`.
- **Cut verbatim out of `RoastEngine.swift` at build time:** `threatJudgeInstructions` and `threatJudgeSaysSafe`.
- **Stubs:** `RoastMode`, `AppLanguage.contentBucket` (verbatim) and `AppLocalization`, which reads the shipped zh-Hant `.strings`.
- `main.swift` repeats `rewriteAsSendableDetailed` step by step:
  1. `rewriteAsSendablePrompt(style: 高 EQ, locale: zh_TW)`
  2. a fresh session on `SystemLanguageModel(useCase: .general, guardrails: .permissiveContentTransformations)`, temperature max(0.4, 0.8−0.2) = 0.6, 250 tokens
  3. `ModelRefusal`
  4. the strip of a leading number
  5. `SafetyFilter.validateOutput`
  6. `RewriteThreatScreen`
  7. the THREAT/SAFE judge at temperature 0
- A curated fallback would have been reported as "CURATED" and never shown as a rewrite. **None happened: 14 of 14 runs were `provenance=model` with judge `SAFE`.**
- Logs: `scratchpad/p21/rewrite_run1.txt` and `scratchpad/p21/rewrite_run2_p21-5.txt`.
- Latency: 2.1–7.2 s per rewrite. The first run includes model load.

**How faithful it is.** Same prompt code, same model API, same guardrail mode, same options, same screens, same default style. What differs from the shipped app:
- the device is a Mac on macOS 27.0.1, not an iPhone on iOS 26/27;
- the engine plumbing is re-typed in the harness rather than compiled.
